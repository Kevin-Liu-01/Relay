## Operation

```sh
npm run build:hosted
npm run test:report
# Supply RAMP_ROUTER_API_KEY privately.
node scripts/run-task-campaign-v2.mjs prepare
node scripts/run-task-campaign-v2.mjs pilot
node scripts/run-task-campaign-v2.mjs status
# After inspecting all first-five-block traces and receipts:
node scripts/run-task-campaign-v2.mjs bulk --reviewed-pilot
node scripts/report-task-campaign.mjs all-tasks-2026-10-03
```

The worker checkpoints requests and episodes, preserves local hash-checked archives, and updates a complete public summary/CSV at each block. Raw archives are not publicly downloadable until separately uploaded. A crash within a block stops collection; it never silently reruns that block. This document preregisters work, not completion.
