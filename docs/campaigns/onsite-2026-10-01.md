# Onsite evidence campaign

## Question and scope

- Can real model policies complete the supported Slack workflows through different interaction gateways, and where do they fail?
- Unit: one fresh workspace and model conversation per episode. Task/seed is the matched block; actions are not independent samples.
- 30 planned development episodes: three pilot cells; 24 workflow cells; three additional pixel cells. One seed, one repetition. No model ranking, confidence interval, held-out generalization, or RL training claim.
- Local Chromium, 1440 × 900, identical application/grader source across phases. Local evidence does not establish cloud screenshot reliability.
- Accessibility and page JSON use element actions. Pixels use coordinates and keyboard input. Actor API changes both visibility and action granularity; report it separately from computer use.

- [Machine-readable plan](onsite-2026-10-01.json): exact models, rates, tasks, seeded randomized order, recent-four history, no supplied guide, no hidden retries.
- Account catalog checked 2026-10-02 05:09 UTC (October 1 locally): GPT-4o mini $0.15/$0.60 and GPT-6 Luna $0.10/$0.50 per million input/output tokens. Catalog hash: `eb4ca2c6b3dffb6c26c48637bc97f1ca9685752b1971f7d235c7a94608ac5a79`.
- Model names are requested routes, not immutable weight revisions. Preserve returned model and request receipts.
- GPT-4o mini accepts image input according to [OpenAI's model documentation](https://developers.openai.com/api/docs/models/gpt-4o-mini). Router image transport is verified in the pilot, not assumed from the account listing.
- Preserve the exact plan and source hashes before inference. Do not change fixtures, prompts, graders or presentation of observations during the campaign.

## Budget and stopping rules

- At most $3 in local estimates: pilot $0.25, workflows $2, pixels $0.75. Reservations are not invoices. Provider-side limits remain necessary.
- Per phase: up to 500 requests, 1,024 output tokens/request, 250,000 conservative input units/request, 240 seconds/episode. Pilot has 20 actions and 600 seconds total; other phases 50 actions and 1,800 seconds total.
- Phase ceilings total 70 minutes; no GPU allocation. Stop on unknown usage, provider failure, audit failure, source drift, interrupted prior phase or exhaustion of a phase budget. Do not silently redistribute allowances or rerun failed cells.
- Inspect the pilot's inputs, actions, state changes, images and audit before starting workflows. A policy failing its task does not itself invalidate the harness; a broken observation or leaked grader does.
- Keep every scheduled cell, including unattempted cells. Preserve partial/incomplete evidence and record any plan amendment separately before more calls.

## Measurements and evidence

- Strict terminal state success, task checks, action attempts, rejected actions, wall time, reported tokens, cost estimate, provider failures, capture gaps and audit integrity.
- Operator screenshots, recorded pointer events and inert UI snapshots are evidence only, never extra policy input.
- Publish only explicitly named synthetic runs after secret/capability scanning. Export original requests, responses, hash-chained events, initial/final states and PNGs. Never publish raw browser traces or the provider key.
- Report all-attempted denominators and separate incomplete execution from completed incorrect tasks. Curated replay examples must link to the complete campaign inventory.

## Run locally

- The commands below record the original capture procedure. This campaign is now
  closed; a fresh checkout refuses to overwrite it. To run a new study, use
  `npm run experiment -- run YOUR_CONFIG.json` with a separately reviewed config.

```sh
npm ci
npx playwright install chromium
npm run build
# Set RAMP_ROUTER_API_KEY privately in the process environment.
node scripts/run-evidence-campaign.mjs pilot
# Inspect the saved pilot and audit before the next phase.
node scripts/run-evidence-campaign.mjs workflows
node scripts/run-evidence-campaign.mjs pixels
```

- Existing phases cannot be overwritten or resumed. A new study needs a new, explicitly reviewed plan.
